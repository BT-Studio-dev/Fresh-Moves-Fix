# Reactions and Glowing Eyes compatibility research

Checked 2026-11-13. The website's additional tools are deliberately separate from the skin editor: neither mod's configuration is a Fresh Moves / Just Expressions PNG marker. Existing marker formats are not repurposed or cleared by these tools.

## Reactions

- [Modrinth Reactions by Tochuuu](https://modrinth.com/mod/playereactions): latest listed Minecraft 26.3 release is 0.9.2 beta (Fabric and NeoForge, November 8). The `reactions` Modrinth slug is a different project.
- [26.3 source at 421e9d66](https://github.com/Tochuuu/Reactions/tree/421e9d66aab6801500fe15a569d294b0307d1b02), the most recent commit as of the check date, reports 0.9.2; later branch updates are not a published 0.9.2 release. The README's 26.1 requirement is stale: use [Gradle metadata](https://github.com/Tochuuu/Reactions/blob/421e9d66aab6801500fe15a569d294b0307d1b02/gradle.properties) for the 26.3 branch.
- [Client config](https://github.com/Tochuuu/Reactions/blob/421e9d66aab6801500fe15a569d294b0307d1b02/common/src/main/java/me/tochuuu/reactions/client/ReactionsClientConfig.java) stores eye and mouth positions, eye size, per-eye layer, eyelid samples and other options in `config/reactions.json`, not in special PNG marker pixels. Legacy `reactions-client.json` is migrated. Face positions use 8–15 even when sourcing layer 2 (offset +32). The editor provides a placement guide and can update an imported existing configuration, retaining its unrelated settings; alternatively set the positions in the mod. 3×3 eyes are blocked upstream.
- The branch's Fabric metadata requires Java 25+, Fabric Loader >= 0.18.5, Fabric API >= 0.161.0+26.3 and Minecraft 26.3; NeoForge metadata requires NeoForge and Minecraft `[26.3,26.3.1)`. Modrinth's Fabric version lists no dependencies, so this requirement comes from source metadata rather than its dependency list. Network sync is optional and uses a server relay; visual behavior needs in-game verification.

## Glowing Eyes

- [Modrinth](https://modrinth.com/mod/glowing-eyes) lists 2.1.3 for Minecraft 1.21.11 (Fabric/Quilt and NeoForge); Fabric/Quilt requires Fabric API. Java 21 is specified by the 1.21.11 source. No 26.3 release is listed as of the check date. Local use is possible without a server installation; multiplayer sharing requires server and client support, per the mod's FAQ.
- [1.21.11 source](https://github.com/RaydanOMGr/GlowingEyes/tree/d8d0d0243d4e50ad6dadabae9c63a6ff704bcccb) has version 2.1.3. Its [PresetManager](https://github.com/RaydanOMGr/GlowingEyes/blob/d8d0d0243d4e50ad6dadabae9c63a6ff704bcccb/common/src/main/java/me/andreasmelone/glowingeyes/client/presets/PresetManager.java), [Preset codec](https://github.com/RaydanOMGr/GlowingEyes/blob/d8d0d0243d4e50ad6dadabae9c63a6ff704bcccb/common/src/main/java/me/andreasmelone/glowingeyes/client/presets/Preset.java) and [Color codec](https://github.com/RaydanOMGr/GlowingEyes/blob/d8d0d0243d4e50ad6dadabae9c63a6ff704bcccb/common/src/main/java/me/andreasmelone/glowingeyes/common/util/Color.java) define `presets.json`: DataVersion 4, a list of named presets, each with a map of absolute `x,y` keys to signed opaque ARGB integers. The default bundled file is DataVersion 3; migration to 4 has no extra fix. Versions before 2 use different point coordinates; this tool refuses to upgrade old files. Back up all preset files before replacing them.
- The in-game editor's skin-part selector includes the four Fresh Moves texture areas, in addition to the head and its overlay; the website offers these parts as well. Version 2.0.0 introduced the skin-part selector and preset format changes; 2.0.2 added local state saving when the server does not have the mod. These are not skin PNG marker changes. Applying a downloaded preset still requires the mod and is not the same as editing the player's active glow state.

The code and release metadata were inspected, but the released binaries and Minecraft runtime were not exercised. Visual compatibility and multiplayer synchronization remain unverified.
