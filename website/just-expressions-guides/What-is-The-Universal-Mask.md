# Why do I need it?

The Universal Mask is required for some animated facial features such as eyebrows, eyelashes, mouths, and even certain eye types like 1x1, 1x2, and 1x3.

Its purpose is to hide the non-animated face, ensuring that only the animated features are visible.

> Without a Universal Mask, you'd need to manually edit the vanilla head texture to prevent duplicated facial elements. This would also result in a faceless face for anyone not using the resource pack.

**So, if any guide mentions the need for a Universal Mask, you MUST add it to your skin image file.**


# How do I do it?

1. Locate the head texture in your skin PNG. It's always in the same area of the skin PNG.
2. In Blockbench, use the selection tool to select the face area of the skin. This is an 8x8 pixel section of the head.
3. Press Ctrl + C to copy the selected face area, then immediately press Ctrl + V to paste it. You’ll now be able to move the duplicated face.
4. Move the duplicated face to the upper right corner of the skin PNG (as shown in the image below).
5. Press Escape to exit selection mode. Then, using the pixel brush and the color picker, edit the duplicated face to remove any facial features.

The goal of the Universal Mask is to remove any duplicate features that would otherwise overlap with the animated ones.

* If your original face had eyebrows or eyelashes, paint over them with the skin tone.
* If your skin had a mouth, paint over it as if it weren’t there.
