# Regular Eyebrows

👉 Want to see all the eye shapes and facial features? [Click here](https://github.com/IthanMendoza/Just-Expressions/wiki/(Full-List)-All-Eye-Shapes-and-Facial-Features) 

To animate this facial feature, you **MUST** also add a **UNIVERSAL MASK 🟨** to the skin. Learn more about [The Universal Mask](https://github.com/IthanMendoza/Just-Expressions/wiki/What-is-The-Universal-Mask)

To place the required pixels, **you'll need to check this area in the skin PNG.** If you don’t know what these **Red areas 🟥** and **Blue areas 🟦** mean, learn more about the [skin PNG Layout](https://github.com/IthanMendoza/Just-Expressions/wiki/Wordbook-(Glossary)#the-skin-png-layout)
